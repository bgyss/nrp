## Post 1 — hook

I thought my first 3D neural-rendering representation had regressed by 3.62 dB.
That result was wrong.

The honest result is subtler: the regression is real, much smaller, and unstable
across seeds. I built a second experiment set to find out why. Thread 🧵

## Post 2 — what was wrong

The 25.24 dB historical 2D baseline used a different validation-light stream and an
older initialization regime. None of its 12 validation lights matched the new run.
It was useful history, but not a valid controlled gate.

## Post 3 — corrected result

On the exact same seed, held-out lights, budget, denoiser, and 3,000 iterations:

2D pixel grid: 22.16 dB
3D world grid: 21.62 dB
delta: −0.544 dB

The gate was −0.5 dB. It still fails—by 0.044 dB, not 3.62 dB.

## Post 4 — more seeds

I ran 3 paired seeds. 3D-vs-2D deltas:

−0.54, −0.77, +0.25 dB

Only 1/3 clears the unchanged gate. Mean is inside it, but averaging away failed
runs would defeat the point. R1 remains an honest negative.

## Post 5 — collision clue

Observed hash collision fractions:

2D pixel grid: 23%
3D world grid: 87%

A 3D lookup touches 8 vertices/level instead of 4, and a matched parameter budget
forces much earlier hashing. That looked like the obvious culprit.

## Post 6 — capacity is not the fix

I gave 3D 199,841 params—88% more than the 2D control. Collisions fell to 67%.
Quality reached 21.75 dB: only +0.13 over matched 3D, still below 2D.

“Use a bigger table” does not explain or repair this result.

## Post 7 — tri-plane attempt

Next: 3 world-anchored 2D grids (XY/XZ/YZ), concatenated. 106,239 params—just +0.15%
vs 2D—and 35% collision rate.

Seed deltas: +1.36, −0.93, −0.36 dB.

Promising mean. Unacceptable variance. 2/3 pass, so no promotion.

## Post 8 — another interaction

Initialization moved absolute PSNR by >2 dB for both 2D and 3D on seed 0, yet their
paired gap still failed.

So this is not one tidy bug. Representation, hash allocation, optimizer state, and
training variance are interacting.

## Post 9 — possible way forward

Next I’m testing 5 paired seeds across init policies, collision-aware table
allocation, tri-plane fusion, rotated world coordinates, and localized errors.
Then a second real scene.

Same rule: every seed must stay within 0.5 dB. No best-seed promotion.

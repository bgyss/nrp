## Delivered Work

### R1: world-space hashgrid at controlled parity — honest negative

Commit `5736a51` added 3D multiresolution hashgrid support (`world3d`) and configs
for toy and Country Kitchen controlled comparisons. Key changes include
`nrp/torch_backend/encoding.py`, `model.py`, `train.py`, inference/optimization
callers, `examples/r1_worldgrid.py`, `examples/r1_{toy,kitchen}_world3d.json`, and
extended torch-backend tests. It also added the R1 tracker and committed report
artifacts under `out/r1-worldgrid/`.

The authoritative controlled gate remains per-run, paired against `pixel2d` at the
same seed/configuration and a no-worse-than −0.5 dB tolerance. The toy seed-0 result
passes (+0.86 dB), but Country Kitchen seed 0 is 21.62 dB for `world3d` versus 22.16
dB for `pixel2d` (−0.544 dB), so R1 is not promoted. The historical 25.24 dB 2D
artifact was re-evaluated at 23.27 dB and marked non-comparable for the gate because
its validation stream and initialization differed.

### R1 follow-up: variance, collision, and tri-plane diagnosis

Commit `fd2b7e8` added `examples/r1_failure_analysis.py`, selectable
`world_triplane` encoding, additional tests, committed replay artifacts under
`out/r1-followup/`, and the next-experiment plan
`docs/plans/2026-07-27-r1-next-experiments.md`. It updated architecture, paper
mapping, performance, representation-tracker, and status documentation. Draft,
unpublished communication copy was added under `docs/social/`.

Three controlled Kitchen seeds produced direct-3D deltas of −0.544, −0.771, and
+0.247 dB (one pass of three). The parameter-matched tri-plane candidate produced
+1.359, −0.935, and −0.356 dB (two passes of three). Tri-plane reduces observed
weighted hash collisions from 86.7% for direct 3D to 35.3%, but still fails the
unchanged per-seed gate. An unmatched 199,841-parameter 3D diagnostic lowers
collisions to 66.6% yet reaches only 21.75 dB on seed 0; more capacity alone did not
repair the gap. `pixel2d` therefore remains the default, while both world encodings
remain experiment-only.

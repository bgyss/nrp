# Status — 2026-07-27

## Representation R1 failure analysis

R1 remains an honest negative, but the original −3.62 dB Country Kitchen headline
has been corrected. The historical 25.24 dB 2D artifact used a different held-out
light stream and predates output-scale initialization; it is not a controlled gate.
On the fixed validation set it scores 23.27 dB.

The binding seed-0 comparison is 22.16 dB for `pixel2d` versus 21.62 dB for
`world3d`, a −0.544 dB delta and a 0.044 dB miss beyond the allowed loss. A
three-seed replay confirms instability:

| candidate | paired deltas vs pixel2d | gate passes | promoted |
|---|---|---:|---|
| direct world3d | −0.544, −0.771, +0.247 dB | 1/3 | no |
| world tri-plane | +1.359, −0.935, −0.356 dB | 2/3 | no |

The selectable tri-plane implementation uses independent XY/XZ/YZ multiresolution
grids and stays within +0.15% of the 2D parameter count. It reduces observed
weighted hash collisions from 86.7% for direct 3D to 35.3%, but its higher
seed-to-seed variance fails the unchanged per-seed gate.

An unmatched 199,841-parameter 3D diagnostic reduces collisions to 66.6% but reaches
only 21.75 dB on seed 0. More capacity alone is not a repair. An initialization
ablation moves absolute seed-0 quality by more than 2 dB for both 2D and 3D without
closing the paired representation gap.

## Decision

- Keep `pixel2d` as the default, paper-faithful path.
- Keep `world3d` and `world_triplane` selectable for experiments only.
- Do not promote either world representation.
- Keep R2–R6 blocked.
- Run the bounded five-seed/allocation/coordinate-robustness ladder in
  `docs/plans/2026-07-27-r1-next-experiments.md` before considering cameras.

Evidence: `out/r1-worldgrid/report.json`, `out/r1-followup/report.json`, and the
per-arm reports under `out/r1-followup/train/`.
